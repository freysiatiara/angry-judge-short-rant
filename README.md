A short, funny rant about a small everyday annoyance — a bus that
was due at 8:04, arrived at 8:47 flashing NOT IN SERVICE, and then
showed up in a pack of three. Written for the
[Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046)
on make.fun.

## Run it

```sh
python3 main.py
```

This writes the rant to `/output/entry.txt` (or `$ENTRY_OUTPUT` /
`$OUTPUT_DIR/entry.txt` when set).
